# Adobe Express setup

## Page structure
1. Header: Swanson Design logo + `SELECTED WORK`
2. Short introductory statement
3. Four project groups:
   - RETAIL / COMMERCIAL
   - EDUCATION / WORKPLACE
   - RESIDENTIAL / HOSPITALITY
   - WELLNESS / FITNESS
4. Three-column project grid on desktop; two-column/tablet and one-column/mobile.
5. Each project: interior-page image, project title, `VIEW PROJECT` button.
6. Footer: SWANSON DESIGN LLC + website.

## Button behavior
For each project, use the corresponding GitHub Pages URL:
`viewer.html?id=PROJECT-SLUG`

Do not link the Adobe Express buttons directly to the Dropbox folder. The custom viewer is intended to be the controlled intermediate step.

## Visual direction
Use the existing Swanson Design identity: restrained charcoal/black, warm champagne/gold accents, pale patterned/architectural background, generous white space, thin rules, editorial typography, and large project imagery.
